# Phaser 飞行躲避游戏

这是一个基于 Phaser 3 的简易飞行躲避小游戏原型。游戏核心概念包括：波次（Wave）与节点（Node），飞机可以自动锁定并摧毁陨石，完成节点后获得强化。

## 功能清单（当前已实现）

- 屏幕尺寸：1600x900
- 飞机：可用键盘（WASD/方向键）移动，鼠标跟随，大小50像素，基础速度375px/s
- 攻击：自动锁定最近陨石（500px范围，0.5s冷却）；玩家也可右键点击陨石手动攻击
- 陨石：三种大小（小/中/大），血量分别为1/2/3；生成概率：50% / 30% / 20%
- 随机轨迹：陨石轨迹具有随机波动与阶段性变化
- 爆炸碎片：陨石被摧毁后会产生若干碎片向四周飞散，碰到飞机会扣血
- 波次与节点：5 个波次构成 1 个节点；完成节点后恢复 1 条命、5 秒护盾、速度提升及陨石减速
- HUD：显示当前生命、时间、节点与波次进度

## 如何本地运行

1. 克隆仓库：

```bash
git clone https://github.com/Wuzixu99684/phaser-game.git
cd phaser-game
```

2. 启动一个本地静态服务器（Phaser 需要通过 HTTP 提供文件）

- 使用 Python 3：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

- 或使用 Node.js 的 serve：

```bash
npx serve .
```

3. 打开浏览器并访问 http://localhost:8000 查看游戏。
